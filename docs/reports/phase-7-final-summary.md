## 📊 修复的关键问题

### 1. Consensus 死锁修复 ⭐⭐⭐

**问题**: NodeContribution 死锁
```go
// 错误代码
func UpdateOnlineTime() {
    mu.Lock()
    CalculateScore()  // 死锁！
    mu.Unlock()
}
```

**解决方案**: 创建不加锁的内部方法
```go
func calculateScoreLocked() { /* ... */ }

func UpdateOnlineTime() {
    mu.Lock()
    calculateScoreLocked()
    mu.Unlock()
}
```

**影响**: 测试从 602秒 降至 <0.5秒（**1200x 性能提升**）

### 2. Wallet 密钥生成修复 ⭐⭐⭐

**问题**: 公钥与私钥不匹配
- CreateAccount 用 derivedSeed 覆盖私钥
- 但公钥没有更新
- 导致签名验证失败

**解决方案**: 使用 KeyPairFromPrivateKey 重新生成密钥对

**影响**: wallet 从 0% 恢复到 100%

### 3. Wallet Sign 方法修复 ⭐⭐

**问题**: Ed25519 私钥 64 字节，Sign 期望 32 字节
**解决方案**: 提取前 32 字节种子
**影响**: 签名验证功能正常

### 4. Wallet ExportPrivateKey 解锁修复 ⭐⭐

**问题**: 锁定钱包无法导出（即使有密码）
**解决方案**: 正确密码时临时解锁
**影响**: 私钥导出功能正常
