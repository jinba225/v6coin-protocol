### 1. Address 模块 ⭐⭐⭐
- **网络前缀解析**: 修复 8 字节前缀提取
- **无效签名测试**: 使用不匹配的私钥创建签名

### 2. Consensus 模块 ⭐⭐⭐
- **死锁修复**: 创建内部不加锁方法 `calculateScoreLocked()`
- **区块奖励计算**: 修复减半点计算
- **交易签名**: 添加缺失的签名字段

### 3. Wallet 模块 ⭐⭐⭐
- **密钥对生成**: 使用 `KeyPairFromPrivateKey` 正确生成
- **签名方法**: 提取 32 字节种子进行签名
- **网络前缀**: 提取 8 字节前缀
- **解锁导出**: 密码正确时允许导出私钥

### 4. Blockchain 模块 ⭐⭐⭐
- **StateRoot 不匹配**: 创建 `mockStateDB` 允许自定义状态根
- **区块添加**: 修复验证流程

### 5. State 模块 ⭐⭐⭐
- **Account.Copy**: 正确复制 `CodeHash` 和 `StorageRoot`
- **updateRootHash**: 返回 32 字节而非 4 字节

### 6. TX 模块 ⭐⭐⭐
- **Mock StateDB**: 使用 IP 字节键而非字符串键
- **测试地址**: 创建正确的 IPv6 测试地址
- **Gas 计算**: 增加费用避免整数除法零值
