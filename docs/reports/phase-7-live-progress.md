## 🔧 本次会话完成的修复

### 1. NodeContribution 死锁修复 ⭐⭐⭐

**问题**:
```go
func UpdateOnlineTime() {
    mu.Lock()
    CalculateScore()  // 死锁！
    mu.Unlock()
}
```

**解决**:
```go
func calculateScoreLocked() { /* 不加锁 */ }

func UpdateOnlineTime() {
    mu.Lock()
    calculateScoreLocked()  // 调用内部方法
    mu.Unlock()
}
```

**影响**: 测试从 600+ 秒降至 <0.5 秒

### 2. wallet 网络前缀修复 ⭐⭐

**问题**: `net.ParseIP()` 返回 16 字节，代码期望 8 字节

**解决**: 提取前 8 字节作为网络前缀

**影响**: wallet 从 0% 提升到 77%

### 3. consensus 测试完善 ⭐⭐

**修复**:
- TestCalculateBlockReward - 正确的减半点计算
- TestAddTransaction - 添加签名字段

**影响**: consensus 达到 100% 通过率
