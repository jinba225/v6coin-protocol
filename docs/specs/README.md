# V6Coin Protocol 技术规范

本目录包含 V6Coin Protocol 的详细技术规范文档。

## 文档结构

- `cn/` - 中文技术规范
- `en/` - 英文技术规范

## 技术规范列表

1. **IPv6 扩展报头规范** - 定义 V6Coin 交易信息如何嵌入 IPv6 扩展报头
2. **CGA 地址映射规范** - 密码学生成地址的生成与验证流程
3. **PoC 共识规范** - 连接证明共识机制的详细设计
4. **交易验证规范** - 交易验证与转发的完整流程
5. **加密算法规范** - Ed25519、AES-256、SHA-256 的使用标准
6. **P2P 网络协议规范** - 节点发现与通信协议
7. **区块链数据结构规范** - 区块与交易的数据结构
8. **RPC API 规范** - 节点 RPC 接口定义
9. **钱包协议规范** - 钱包与节点的交互协议
10. **跨链协议规范** - V6Coin 与其他区块链的互操作规范

## 规范版本控制

- 主版本号：重大架构变更
- 次版本号：新功能添加
- 修订号：Bug 修复和优化

## 规范审批流程

1. 技术提案：创建 GitHub Issue
2. 社区讨论：在 GitHub Discussions 中讨论
3. 技术评审：核心团队评审
4. 社区投票：DAO 投票
5. 正式发布：发布新版本规范

## 规范维护

- 规范应与代码实现保持同步
- 规范变更需要相应更新代码
- 规范文档应包含示例代码
- 规范变更需要在 CHANGELOG 中记录
