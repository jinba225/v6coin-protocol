# V6Coin Protocol 技术白皮书

## 核心技术

### 1. IPv6 扩展报头集成
- Hop-by-Hop Options Header (0x7F)
- 交易数据嵌入 IPv6 数据包
- UDP/ICMP 退化封装方案

### 2. CGA 地址映射
- Ed25519 密钥对生成
- IPv6 接口标识符 (IID) 派生
- 临时地址动态切换机制

### 3. PoC 共识机制
- 连接证明 (Proof of Connection)
- 贡献度计算模型
- 验证节点选举机制
- 前缀反垄断机制

### 4. 交易处理
- 在线实时交易
- 离线延迟交易
- 资产迁移交易
- QoS 优先级映射

### 5. 加密与安全
- Ed25519 数字签名
- AES-256-GCM 加密
- SHA-256 哈希
- 环签名匿名性

## 性能指标

| 指标 | 目标值 |
|------|--------|
| 区块间隔 | 10 秒 |
| 交易确认延迟 | ≤30 秒 |

| 全网 TPS | ≥1,500,000 (10000节点) |
| 最小单位 | 1 nano-V6 (10⁻⁹) |
